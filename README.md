
# MIT 8103 – Advanced Database Systems

## Sotai Digital Solutions

### Enterprise IT Service Management and Asset Monitoring System

**University:** Miva Open University  
**Programme:** Master of Information Technology  
**Academic Session:** 2026/2027  
**Course:** MIT 8103 – Advanced Database Systems

## Project Overview

This portfolio demonstrates the design, implementation,
optimisation, and management of an advanced database
system for Sotai Digital Solutions.

The system supports:
- IT service ticket management
- Enterprise asset monitoring
- Endpoint security monitoring
- SLA management
- Technician assignment and escalation
- Reporting and audit logging

## Technologies

- PostgreSQL
- MongoDB
- SQL
- Docker
- GitHub Codespaces

## Portfolio Components

1. Database Design and Modelling
2. Query Processing and Optimisation
3. Transactions and Concurrency
4. NoSQL and Advanced Data Models
5. Distributed and Cloud Database Exercise
